Flip Picker · A Coworker Labs project · Private beta

Algorithmic trading infrastructure, running against real capital.

Flip Picker is Coworker Labs’ in-house trading platform — institutional flow, catalyst-speed news, options Greeks, short-interest, and per-ticker Bayesian calibration stitched into a single self-correcting system. It is the testbed where every orchestration pattern we design for clients gets pressure-tested before it leaves the building.

01 The architecture

Seven data layers, one orchestrated decision engine. Every layer has graceful degradation, full provenance tracking, and a measured confidence weight that flows through to the final signal.

L1 · Price
Live quotes with multi-source fallback. Pre/post-market aware.
L2 · Flow
Institutional options flow, dark pool, sweeps. No silent fallback — flow gaps are flagged loudly.
L3 · Greeks
Real-time first-order Greeks via v3 endpoints, Black-Scholes fallback from live IV.
L4 · Squeeze
Short interest, cost-to-borrow, days-to-cover, locate availability.
L5 · GEX
Locally computed gamma exposure. Positive = suppression; negative = expansion.
L6 · Regime
VIX term structure, market breadth, macro factors — composite regime classifier that adjusts every layer’s weight.
L7 · Memory
Per-ticker Bayesian posterior. Cold-start priors give way to data-driven estimates at n=20+ samples.

Layered on top: a calibration loop that runs weekly, a risk enforcer that flags hard stops / trim locks / theta cliffs in real time, and an output evaluator that grades every recommendation before it surfaces.
